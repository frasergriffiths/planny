# Icons

A curated set of Heroicons 24px outline icons, inline in the plan. Copy the SVG into the HTML and keep `stroke="currentColor"` so the icon takes the text colour. The set is small on purpose: use an icon when it helps someone scan a section, not on every heading.

Icons must stay inline. planny strips external files and remote requests, so an `<img>` or icon font will not render. Do not add `<script>` or event handlers to an icon.

## Usage

```html
<div class="spine-head">
  <span class="spine-icon" aria-hidden="true">
    <svg width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="1.5" stroke-linecap="round" stroke-linejoin="round" aria-hidden="true">
      <path d="..." />
    </svg>
  </span>
  <div><div class="eyebrow">Who</div><h2>...</h2></div>
</div>
```

Size icons with the `width` and `height` attributes. `stroke-width="1.5"` matches the template headings. Every icon carries `aria-hidden="true"`; put the meaning in the adjacent heading or label.
