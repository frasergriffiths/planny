Ship the agent plan workspace.

An eight-week plan to turn one HTML file into a durable, shareable plan link, without adding an account system or a dashboard nobody asked for.

Owner: Fraser Updated: 19 Oct 2026 Horizon: 8 weeks Status: Active
TL;DR
  • Ship the private Blob store and the view route first. An upload path without a reliable read is a demo, not a product.
  • Keep the viewer script-free and link-free. The sanitiser is the product boundary, not a cleanup step.
  • Measure time to first plan and repeat views. There are no accounts, so signups are not a metric.

What we are building

An agent writes one HTML plan, publishes it with a name and a duration, and gets a link. The link is the only key. The plan renders in a sandbox with no scripts, no links and no external requests, so it can be visual without becoming a page that can phish.

Next steps

  • Replace the public store. Delete it, create the private store in LHR1, and rotate the burned token.
  • Set the environment. Address key, admin token, Blob token, Upstash URL and token, Global Config.
  • Prove the pause matrix. One read, then a 503 with the guard name, reset date and no-store.
  • Prove the region. /health returns 200 ok, and the raw x-vercel-id has an lhr1 function segment.
  • Install the skill. Publish, view, delete and 410 from the command line, then from an agent session.
Confidence

Two unknowns remain: the private store cutover and the preview region. Both have owners and dates.

Open questions

  • Does the preview need its own Upstash database, or is the prefix enough?
  • Is 4 MiB enough for a plan with embedded screenshots?
  • Who reads the abuse inbox after launch?

Definition of done

  • An upload returns a link and a delete key.
  • The link renders with no external requests.
  • Expired, deleted and taken-down links return 410.
  • A pause returns 503 with the guard and reset date.
  • The skill publishes, views and deletes from an agent session.
