What this sample shows

A plan can be one self-contained page: a hero, a timeline, milestones, decisions, risks and next steps. This sample uses the dark planny palette, inline SVG and CSS, and no external files. It is a real page you can open at a link, not a screenshot.

Next steps

  • Write your plan. Start from the dark template. Keep it one HTML file.
  • Publish it. Give it a name and a duration. Keep the link and the delete key.
  • Share the link. Anyone with the link can read it. No account is needed.
  • Delete it when done. The author delete returns 410 and removes the key file.
  • Keep it under 4 MiB. Embedded images count toward the cap.
